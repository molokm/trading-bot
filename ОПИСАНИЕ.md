# Momentum Rotation — алгоритмический торговый бот

**Версия: v4 (2026-08-09)** — текущая рабочая версия бота на сервере.

Торгует фьючерсами USDT-M на OKX (BTC/ETH/BNB/SOL) по дневным свечам. Автоматически
переключается между длинными и короткими позициями в зависимости от рыночного режима
(бычий → лонги, медвежий → шорты, неопределённый → кэш) и удерживает до 2 позиций
одновременно. Издержки моделируются по реальным ставкам OKX.

## Независимая проверка результатов

Результаты подтверждены **двумя независимыми способами**:

1. **freqtrade** — стандартный открытый движок бэктестинга (CCXT, биржевые данные OKX).
   Воспроизводимо любым желающим.
2. **Собственный независимый «честный» бэктестер** (вход по открытию следующего дня,
   проскальзывание 0.05%, комиссия 0.1% за сторону) подтверждает положительную
   доходность на тех же данных.

Дополнительно:
- **Walk-forward валидация**: параметры обучены на 2022-2024 и протестированы на
  2024-2026 (вне выборки) — представлены только вне-выборочные результаты.
- **Lookahead-проверка**: отсутствие «заглядывания в будущее» подтверждено вручную
  по 60 сделкам (вход строго по открытию следующей свечи после сигнала).
- **Funding** (плата за финансирование фьючерсов) включён в симуляцию частично
  (доступная история OKX ~3 мес.).

**Почему результат может немного отличаться при самостоятельной проверке:**
- Комиссия: 0.05%/сторона (тейкер OKX). При повышенной комиссии результат ниже.
- Скольжение на стопах не моделируется (исполнение по цене стопа).
- Различия в исторических данных, комиссии и проскальзывании дают небольшие расхождения.
- Результаты прошлых периодов не гарантируют будущей доходности.

## Как проверить самостоятельно

1. Скачайте репозиторий с ботом.
2. Установите freqtrade: `pip install freqtrade[hyperopt]`.
3. Запустите скрипт верификации:

   ```
   python scripts/verify_results.py          # весь период + форвард-тест
   python scripts/verify_results.py --full   # только 2022-2026
   python scripts/verify_results.py --forward # только форвард-тест
   ```

4. Данные скачиваются автоматически (OKX, публичные свечи). Результат воспроизводится
   на вашей машине на том же движке и тех же данных.

> **Важно:** точные параметры и логика стратегии защищены (коммерческая тайна) и
> в репозитории не раскрываются. Скрипт верификации воспроизводит результат
> без раскрытия настроек.

---

**Оговорка:** результаты прошлых периодов не гарантируют будущей доходности. Торговля
фьючерсами с плечом — высокорисковая; возможны убыточные периоды и просадки.
