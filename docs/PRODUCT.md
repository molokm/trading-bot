## Что это сейчас

**COPIX** — веб-терминал + Telegram Mini App для **одного** торгового бота:
**AI Discretionary 1H** на фьючерсах USDT-M биржи OKX (BTC / ETH / SOL / XRP).

Продукт работает в режиме `AI_ONLY_MODE` (жёстко включён в
[backend/app/main.py](../backend/app/main.py)): Momentum Rotation, Impulse 1D, Validation,
Order Book Scalp (OBI), VWAP Mean Reversion, AI Scale-In и Smart Money **выведены из
эксплуатации** — от них остались заглушки
[backend/app/services/legacy_stubs.py](../backend/app/services/legacy_stubs.py), а их
эндпоинты отдают `{"retired": true}`.

Прод: `https://trading-bot-mu99.onrender.com` (Render, free tier).

### Как бот принимает решения

- Раз в 1H-бар формируется снапшот рынка (индикаторы + режим) и передаётся LLM
  (OpenAI-совместимый API: Groq → OpenRouter → OpenAI, при недоступности — `mock_decide`);
  решение проходит через набор вето (ADX, ROC, EMA200, R/R, funding, дневной лимит убытка,
  risk-manager‑вето второй моделью).
- Позиция одна, плечо ограничено (базово до 3×), риск на сделку ~1.2% капитала,
  стоп/тейк выставляются **реальными conditional-ордерами на OKX** и правятся при трейлинге.
- **DEMO — единственный «мозг».** **LIVE — строгое механическое зеркало DEMO**,
  самостоятельная торговля на LIVE запрещена на уровне инвариантов, проверяемых в рантайме
  ([backend/app/services/ai_strategy.py](../backend/app/services/ai_strategy.py),
  [tests/test_mirror_strict.py](../tests/test_mirror_strict.py)).

### Монетизация

Telegram Stars: тариф **Pro** (по умолчанию 500 ⭐ / 30 дней) — доступ к Mini App,
подключение собственных ключей OKX и автоторговля. Бесплатный тариф — сигналы в канале
(платный канал сигналов и тариф «Сигналы» выведены).

### Независимая проверка результатов

1. **freqtrade** — стандартный открытый движок бэктестинга (CCXT, биржевые данные OKX).
2. **Собственный независимый «честный» бэктестер** (вход по открытию следующего дня,
   проскальзывание 0.05%, комиссия 0.1% за сторону).

Дополнительно:
- **Walk-forward валидация**: параметры обучены на 2022-2024 и протестированы на
  2024-2026 (вне выборки).
- **Lookahead-проверка**: отсутствие «заглядывания в будущее» подтверждено вручную
  по 60 сделкам (вход строго по открытию следующей свечи после сигнала).
- **Funding** включён в симуляцию частично (доступная история OKX ~3 мес.).

Оговорки: комиссия 0.05%/сторона (тейкер OKX); скольжение на стопах не моделируется;
различия в данных и издержках дают небольшие расхождения; прошлые результаты не
гарантируют будущей доходности.

### Как воспроизвести

```bash
pip install freqtrade[hyperopt]
python external/scripts/verify_results.py            # весь период + форвард-тест
python external/scripts/verify_results.py --full     # только 2022-2026
python external/scripts/verify_results.py --forward  # только форвард-тест
```

Данные скачиваются автоматически (публичные свечи OKX). Точные параметры стратегий в
репозитории не раскрываются.
